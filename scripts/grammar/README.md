# 语法标注工具链（探针阶段产物）

用于把「句子 → 语法标注」跑通，校验它符合 `COURSE_CREATION_FORMAT.md`，并渲染出效果页。
这套脚本是**探针**（验证设计可行性），不是最终实现——最终实现要进 API 的 `ai-content` 管道。

## 视觉结构（用户逐条拍板，改前先读）

```
  主语          谓语          宾语        ← 成分名: 在胶囊**上方**、与胶囊居中、颜色 = 胶囊描边色
┌─────┐     ┌──────┐     ┌──────────┐
│  I  │     │ like │     │ the food │     ← 浅彩底 + 亮色描边 + **深色词**
└─────┘     └──────┘     └──────────┘
 ▁▁▁▁▁       ▁▁▁▁▁        ▁▁▁▁▁  ▁▁▁▁▁      ← 每个单词一条下划线（亮色）
  代词        动词          冠词    名词       ← 词性: 与词/下划线**同一条中心线**、颜色一致
```

### 配色 = **亮色系**：浅彩底 + 亮色描边/点缀 + 深色词

参考图（用户提供）的规律，**直接取像素得到、不要凭眼睛估**：

- 胶囊本体（装词）＝ **浅彩底 + 亮色描边**，英文词用**深色字**压在上面
- 成分名 / 下划线 / 词性文字 ＝ 同色族的**亮色**（高饱和）
- ⚠️ **深色饱和底 + 白字是被否的一版**（用户原话「颜色不对，参考这种亮色」）

每族三个值 `bg` 浅彩底 / `ink` 深色词 / `acc` 亮色点缀 —— 见规范 §10.0 的完整表。
对比度全程实算：词压浅底 6.27–13.01:1、亮色压白底 4.60–7.58:1。

取色工具：`$LOCALAPPDATA/Temp/ew-extract-palette.py`（按频次聚类取色）、
`ew-scan-blocks.py`（按横向分桶取每块的浅底/饱和配对）。**别用记忆里的近似色。**

### 被用户否掉的三版（别改回去）

1. 单词各自装进小卡片 + 胶囊只写成分名 → 看着像「**一个单词一个气泡胶囊**」。
2. 胶囊写成分名、单词在胶囊外面、再用一条长横条跨过整段 → 仍不是「成分合在一个胶囊里」。

**正解：胶囊里装的就是英文词本身。**

### 下划线配色两套（用户要求 A/B 对比，页面上一键切换）

- **A 按词性**：代词一色 / 动词一色 / 名词一色…（词性色板，与成分色是两套颜色）
- **B 跟随成分**：下划线与词性文字用所属成分的颜色（与上方胶囊同色）

两套色板都**实算过对比度**（`scripts/ew-contrast.py`）：词性 11 色白字 ≥ 5.02:1；
成分 7 色白字 ≥ 5.17:1，且当文字压白底也 ≥ 5.17:1（成分名要用它当字色）。

## 关键设计（四条，别改坏）

1. **不让模型数字符位置**。模型只输出短语/词的**原文**，偏移由脚本按空白走位算出来
   —— `english.slice(start,end) === text` 构造性成立（实测 0 次偏移错误）。
2. **不让模型写 `structure`**。模型只输出闭集 `pattern`，`structure` 由脚本按映射表算
   —— E13 构造性成立。⚠️ 实测：交给模型写时 **100/100 条**与 pattern 对不上。
   **凡是程序能确定性做对的，就别交给模型。**
3. **`words` 与 `phrases` 是两个数组**：前者逐词标词性（每词恰一条），后者短语标成分（可跨词）。
4. **碎片（`isSentence=false`）不给成分**：`role`/`roleType` 为 `null`；效果页用中性灰胶囊表示
   「这些词是一块」，不声称任何成分。

## 渲染层的三个坑（都会让结果错得很隐蔽）

1. **短语必须按「起点」排序，不能按「文本首次出现位置」排序**：重复出现的词会让后者乱序，
   于是渲染时 `cursor` 乱走、**重复输出已覆盖的词**（实测一条 14 词的句子渲染出 21 个词，
   连带把宽度测量算成 1499px，真实 600px）。`verify-effect-page.js` 的逐句词序断言专门钉这条。
2. **胶囊底色用 `grid-column: 1/-1` 时，词/下划线/词性必须显式写 `grid-column`**：
   grid 自动排布会「避开已占用格子」把词挤到下一行 → 三者中心线错位（实测 871 处）。
3. **换行后 `scrollWidth` 只等于容器宽**，拿不到自然宽 → 必须量「各行成分组宽度之和 + 组间间隔」。
   另外「从句**有意**断行」与「宽度不够**被迫**折行」是两件事，混用会得出反向结论。

## 已实测结论（2026-09-15）

- 「零基础学英语 · 第一课」**218 条全部标注成功**：完整句 100 / 碎片 118
- 完整规则集（E1–E13）**0 条不合格**；`pattern` 收敛到 9 种；`clauseType` 100 条齐全
- 效果页验收：**218/218 句**词序一致、**389 个**成分胶囊、四卡片齐全、无横向溢出、无 JS 报错
- 排版实测（当前版式）：最大单行需宽 **651px**；面板可用宽 **≥820px 时 100% 不折行**
